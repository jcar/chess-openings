# references/

Personal reference material used while authoring opening content: books, PDFs,
scans, notes. **Everything in this folder is gitignored** (see `.gitignore`) and
must stay that way.

Why: chess *facts* — moves, lines, positions, evaluations — are not
copyrightable and are reused freely throughout `src/content/`. The *prose* of a
book is copyrighted. Reference material is read to understand ideas; every
explanation shipped in this app is written from scratch.

Do not commit files here, and do not paste passages from them into content.
